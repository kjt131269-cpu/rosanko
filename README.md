# 로산꼬 전국일주 룰렛 — 설치 안내

어느 기기에서 접속해도 같은 기록이 보이도록 만든 버전입니다.
폰으로 돌린 결과가 태블릿과 노트북에도 바로 반영됩니다.

전부 무료 요금제 안에서 돌아갑니다. 총 20분 정도 걸립니다.

---

| 파일 | 용도 |

| `README.md` | 이 문서 |

## 1단계 — Supabase 데이터베이스 만들기

1. https://supabase.com 접속 → **Start your project** → GitHub 계정으로 가입
2. **New project** 클릭
   - Name: `rosanko`
   - Database Password: 아무거나 (안 쓰지만 어딘가 적어두세요)
   - Region: **Northeast Asia (Seoul)** 선택
3. 생성까지 2분 정도 기다립니다
4. 왼쪽 메뉴에서 **SQL Editor** → **New query**
5. `supabase-setup.sql` 내용을 통째로 복사해 붙여넣고 **Run**
6. 아래에 Success 가 뜨면 완료입니다

---

## 2단계 — 열쇠 두 개 복사하기

1. 왼쪽 메뉴 맨 아래 **Project Settings** (톱니바퀴) → **API**
2. 두 값을 복사해둡니다

| 항목 | 생김새 |
|---|---|
| **Project URL** | `https://abcdefgh.supabase.co` |
| **anon public** | `eyJhbGciOi...` 로 시작하는 긴 문자열 |

`service_role` 키는 **절대 쓰지 마세요.** 반드시 `anon public` 쪽입니다.

---

## 3단계 — index.html 에 붙여넣기

`index.html` 을 메모장이나 VS Code로 열면 위쪽에 이 부분이 있습니다.

```js
const SUPABASE_URL  = "여기에_PROJECT_URL_붙여넣기";
const SUPABASE_KEY  = "여기에_ANON_PUBLIC_KEY_붙여넣기";
const FAMILY_ID     = "rosanko";
```

따옴표 안의 글자만 바꾸고 저장하세요.

```js
const SUPABASE_URL  = "https://abcdefgh.supabase.co";
const SUPABASE_KEY  = "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...";
const FAMILY_ID     = "rosanko";
```

**따옴표를 지우지 않도록** 주의하세요.

## 4단계 — Vercel 에 올리기

### 방법 A — 드래그 앤 드롭 (제일 쉬움)

1. https://vercel.com 접속 → GitHub 계정으로 가입
2. **Add New** → **Project** → 아래쪽 **Deploy** 또는 **Browse** 영역에
   `index.html` 과 `vercel.json` 이 들어 있는 **폴더째로** 끌어다 놓기
3. **Deploy** 클릭
4. 1분 뒤 `https://무언가.vercel.app` 주소가 나옵니다

### 방법 B — GitHub 연동 (나중에 수정이 편함)

1. GitHub 에 새 저장소를 만들고 세 파일을 올립니다
2. Vercel → **Add New** → **Project** → 그 저장소 선택 → **Deploy**
3. 이후 GitHub 에서 파일만 고치면 자동으로 반영됩니다

도시 목록을 자주 바꾸실 생각이면 B 를 권합니다.

## 5단계 — 확인

1. 받은 주소를 폰에서 엽니다
2. 화면 위쪽 점이 **초록색**이고 "모든 기기에서 같은 기록" 이 뜨면 성공입니다
3. 한 번 돌려보고, 다른 기기에서 같은 주소를 열어 기록이 똑같은지 확인하세요

## 알아두실 점

**주소를 아는 사람은 누구나 보고 고칠 수 있습니다.** 로그인을 붙이지 않았기 때문입니다. 가족끼리만 쓰는 도구라 이렇게 만들었고, 새어나가도 손해는 여행 기록뿐입니다. 다만 영상에 주소가 그대로 찍히지 않도록 조심하세요.

**"전부 지우기" 는 모든 기기에서 함께 지워집니다.** 아이가 실수로 누르면 3년치 기록이 날아갑니다. 확인 창을 넣어뒀지만, 종이 지도에 스티커로도 같이 남겨두시길 권합니다.

**무료 요금제로 충분합니다.** 가족 다섯이 격주로 쓰는 정도면 Supabase 무료 한도의 1% 도 안 씁니다.

**Supabase 무료 프로젝트는 일주일간 접속이 없으면 잠깁니다.** 대시보드에서 버튼 한 번으로 다시 깨울 수 있습니다. 격주로 쓰시면 걸릴 수 있으니, 잠겼다는 안내가 보이면 당황하지 마세요.

## 도시 목록 고치기

`index.html` 안에서 `const DATA = {` 부분을 찾으면 됩니다.

```js
"경기 남부": ["수원","용인","안성","이천","여주","화성"],
```

따옴표와 쉼표 형태만 지키면서 이름을 넣거나 빼시면 됩니다.
한 권역에 **6개를 넘지 않는 게** 좋습니다. 글자가 겹쳐 보입니다.

제주 목록은 `const JEJU = [` 부분입니다.
제주 특별전이 열리는 주기는 `const STEP = 10;` 의 숫자를 바꾸면 됩니다.
